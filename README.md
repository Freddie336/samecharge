# SameCharge (provisional)

## Durumu (Status)
**Pre-implementation**

Bu proje henüz geliştirme aşamasına (kod yazma fazına) geçmemiş olup, planlama, tasarım ve mimari doğrulama aşamasındadır. Henüz production-ready (canlıya hazır) değildir.

## Açıklama
SameCharge, 18 yaşından büyük kullanıcıların anlık batarya yüzdelerine göre eşleştiği bir dating/arkadaşlık uygulaması prototipidir.

- **Platform:** Android-first Flutter (provisional)
- **Veritabanı ve Sunucu:** Firebase (Firestore, Realtime Database, Cloud Functions)
- **Tasarım:** Modern batarya temalı minimalist tasarım sistemi.
